Empleo Remoto Pablo V5.3

Herramienta personal y privada para buscar oportunidades de trabajo remoto, generar tres reportes diarios en Excel y enviarlos únicamente a la cuenta del propietario.

Uso de Google

La aplicación usa Gmail para enviar los reportes al mismo propietario y para comprobar en la carpeta Enviados que cada mensaje exista una sola vez y que el archivo adjunto sea exactamente el generado.

No publica correos, no comparte datos con terceros, no vende datos y no utiliza datos de Google para publicidad ni para entrenar modelos.

Alcance operativo

La aplicación es de uso personal, con un único usuario autorizado. La automatización se ejecuta en un repositorio privado mediante GitHub Actions. No escribe en el archivo MASTER de OneDrive.
