Política de privacidad

Empleo Remoto Pablo V5.3 es una aplicación personal usada únicamente por su propietario. Esta política explica cómo utiliza datos de Google.

Datos a los que accede

La aplicación solicita permiso para enviar correos y consultar Gmail en modo de solo lectura. La consulta se limita operativamente a la carpeta Enviados para buscar los reportes generados por la propia aplicación, evitar duplicados y verificar el nombre y la huella criptográfica del archivo Excel adjunto.

Uso de los datos

Los datos de Gmail se usan exclusivamente para enviar y comprobar los reportes diarios de oportunidades de trabajo remoto. No se usan para publicidad, elaboración de perfiles comerciales, entrenamiento de modelos ni decisiones crediticias o laborales automatizadas.

Almacenamiento y protección

Las credenciales OAuth se guardan como secretos cifrados de GitHub Actions y no se incluyen en el código, los reportes ni los registros. La aplicación conserva solo identificadores técnicos del mensaje, estado de entrega y huella SHA-256 del adjunto durante una ventana operativa corta. Los reportes y evidencias de ejecución tienen retención limitada.

Transferencia y divulgación

No se venden, alquilan ni comparten datos de Google con terceros. GitHub Actions procesa la automatización como proveedor de infraestructura del propietario. Los correos se envían únicamente a la propia cuenta autorizada.

Retención y eliminación

Los artefactos operativos expiran normalmente entre 7 y 14 días. El índice técnico conserva únicamente datos mínimos de oportunidades y recibos recientes. El propietario puede revocar el acceso en cualquier momento desde la seguridad de su Cuenta de Google y eliminar los secretos del repositorio privado.

Alcance limitado

El uso de información recibida de las APIs de Google cumple la Política de Datos del Usuario de los Servicios de las APIs de Google, incluidos los requisitos de Uso Limitado.
